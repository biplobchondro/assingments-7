What is JSX, and why is it used?
=>JSX হলো JavaScript এর মধ্যে HTML এর মতো syntax, যা React এ UI তৈরি করতে ব্যবহৃত হয়।
What is the difference between State and Props?
=>Props হলো একটি component কে বাইরের থেকে দেয়া তথ্য বা ডাটা। সাধারণত parent component থেকে child component এ props পাঠানো হয়।
What is the useState hook, and how does it work?
=>useState হলো React এর একটি Hook যা functional component এর মধ্যে state ব্যবস্থাপনা করার জন্য ব্যবহার করা হয়। React এর পুরানো  functional component এ state ব্যবস্থাপনা করতে useState ব্যবহার করা হয়
